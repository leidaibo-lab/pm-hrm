# pm-hrm

pm-hrm 是一个面向 HRM（Human Resource Management）领域的 AI 产品管理与交付实践项目，借助 AI 完成从产品发现、需求澄清、PRD、用户故事、验收标准到后续实现和验证的需求闭环。

它不是单纯的 HRM 业务代码仓库，也不是只保存需求文档的项目。项目目标是沉淀一套可复用的 AI 协作流程，并通过真实的 HRM 业务场景验证这套流程能否持续交付有效产品。

## 两类工作与资料入口

| 类别 | 目标与内容 | 入口 |
| --- | --- | --- |
| 产品协作过程 | 产品角色围绕业务诉求，逐步讨论、确认规则并形成产品版本；保存探索、决策、TODO及产出检查 | [产品协作入口](docs/product/README.md#一产品协作过程如何形成产品版本) |
| 研发交付产物 | 将达成一致的产品整理为当前PRD及配套需求，供研发／测试阅读、宣讲、实施和验收 | [产品输出目录](docs/output/README.md) |

正式输出包含产品项目总览、基础资料管理PRD、招聘管理PRD和验收附件。两类资料分别组织；产品讨论确认后同步交付正文，研发无需遍历确认历史。宣讲发现的新业务问题返回产品协作过程处理。

## AI 需求闭环

```text
产品发现 -> 假设验证 -> 需求澄清 -> PRD -> 用户故事
    -> 验收标准 -> 技术实现 -> 测试验证 -> 反馈迭代
```

AI 在项目中承担协作助手角色，帮助整理信息、发现遗漏、形成文档、拆解任务和辅助验证；业务决策、权限边界和最终验收仍由团队确认。

## 工作原则

- 先验证问题，再设计功能。
- 用 AI 加速分析、记录和拆解，但不替代业务决策。
- 先定义角色、权限和敏感数据边界，再讨论实现。
- 每次讨论沉淀为可追溯的产品文档。
- 产品范围确认前，不提前创建业务代码和数据库结构。
