# 字段与表单校验规范

## 文档信息

- **版本／日期**：0.1／2026-10-14。
- **面向读者／用途**：研发、测试与设计；公共输入、提交及反馈要求。
- **适用范围**：本期基础资料、平台支撑及招聘管理。
- **状态**：当前版本需求定义。

## 版本与变更记录

| 版本／日期 | 变更与影响 |
| --- | --- |
| 0.1／2026-10-14 | 分开表达格式、密码、附件、提交和交互规则；招聘特有的数量及时长参数归对应字段，校验边界保持不变。 |

## 目标

同类输入采用一致的格式、长度与错误反馈。前端及时提示，服务端在提交时重新校验；具体字段的必填条件、默认值和业务准入由页面需求定义。

## 公共规则

### 基础输入校验

| 规则对象 | 适用范围 | 长度／取值 | 校验与处理 |
| --- | --- | --- | --- |
| 必填输入 | 页面定义为必填的字段 | 不接受null、空字符串或纯空白 | 文本去除首尾空白后校验；密码保留原始输入，不裁剪 |
| 普通单行文本 | 未定义更严格上限的单行字段 | 最多100个用户可见字符 | 按用户可见字符计数，不静默截断 |
| 备注文本 | 备注类字段 | 最多2,000个用户可见字符 | 按用户可见字符计数，不静默截断 |
| 长文本 | 长文本字段 | 最多5,000个用户可见字符 | 按用户可见字符计数，不静默截断 |
| 姓名／显示名 | 人员及候选人姓名、用户显示名 | 1—50个字符 | 允许中文、英文、数字、空格和常见连接符；不能仅由空白组成 |
| 邮箱 | 账号邮箱、候选人邮箱 | 最多254个字符 | 校验邮箱格式；比较唯一性或同类匹配时忽略大小写、去除首尾空白。是否要求唯一由相应字段定义 |
| 手机号 | 使用电话号码的字段 | 国家码及号码最多15位数字；中国大陆号码11位 | 标准化为国家码及数字；国际号码需国家码，不将其他国家号码套用大陆规则。是否必填及是否判重由相应字段定义 |
| 正整数 | 数量、排序等正整数字段 | 整数且大于0 | 拒绝小数、0和负数；业务上限由相应字段定义 |
| 链接 | 外部来源等链接字段 | 最多2,048个字符；http或https | 保存前校验格式，展示时使用安全跳转 |
| 日期时间 | 日期及时间输入 | 有效日期时间 | 使用Asia/Shanghai；有起止关系时结束不早于开始，模块更严格条件同时适用 |
| 字典选项 | 引用公共字典的字段 | 新记录、新增关联或换值仅启用项 | 原停用关联的编辑、提交时停用与错误反馈见[字典停用值的历史编辑](#字典停用值的历史编辑d-030) |

### 密码校验与保护

| 规则项 | 输入／校验要求 | 使用与保护要求 |
| --- | --- | --- |
| 长度及字符 | 15—128个字符；允许空格、Unicode及粘贴，不强制字符类别组合 | 不做首尾空白裁剪，允许密码管理器；临时密码使用相同校验 |
| 弱密码 | 拒绝常见、已泄露及与账号信息完全相同的密码 | 显示校验失败及修正方向，不回显密码内容 |
| 密码更新 | 不定期强制改密；泄露或管理员重置后要求更新 | 首次登录及重置后改密流程见基础资料PRD；密码不能写入普通日志 |

### 附件准入与访问

| 规则项 | 准入要求 | 保存与反馈 |
| --- | --- | --- |
| 格式 | PDF、DOC、DOCX；同时校验扩展名、MIME及实际内容 | 内容与声明不匹配时拒绝，不仅根据扩展名放行 |
| 文件大小 | 单份不超过20 MB | 超限拒绝；上传耗时按运行基线验收 |
| 文件内容 | 不接收加密、损坏、带宏或可执行内容 | 无法识别时拒绝并提示转换为PDF |
| 上传失败 | 失败不形成可用附件 | 不留下孤立附件记录；当前简历及版本更新按招聘页面规则执行 |
| 文件访问 | 访问时校验当前权限；不提供永久公开链接 | 查看和下载分别授权，失败不暴露完整附件路径 |

### 文本展示与错误信息安全

| 场景 | 处理规则 |
| --- | --- |
| 展示用户输入 | 转义显示，不执行其中的脚本或HTML |
| 展示错误信息 | 不返回堆栈、文件路径、密码及其他敏感内容；说明可识别的业务原因 |

## 提交校验、并发与重试

| 场景 | 提交判定 | 结果与反馈 |
| --- | --- | --- |
| 前端已校验 | 服务端仍复核字段、权限、当前记录及业务条件 | 前端通过不等于允许保存 |
| 重复提交／失败重试 | 创建、状态变更、合并、上传等动作防止重复执行 | 同一成功动作重试不重复生成业务记录、轮次或待办 |
| 并发版本冲突 | 创建、状态流转、删除、跳轮、合并等提交不覆盖过期版本 | 拒绝并提示刷新；保留合法输入，不部分保存 |
| 权限或责任变化 | 提交前复核账号、角色及适用指派的当前状态 | 禁用账号、失效角色或责任指派不能沿用旧页面授权；拒绝反馈不泄露越权信息 |
| 选项停用 | 新关联复核选项启用状态；历史保留按字典管理规则判断 | 已停用值不用于新关联，原关联不因编辑无关字段被强制替换 |

## 通用交互要求

| 场景 | 用户反馈 | 输入及数据结果 |
| --- | --- | --- |
| 字段校验失败 | 错误显示在对应字段附近，说明原因和修正方向 | 保留合法输入，供继续编辑 |
| 服务端拒绝 | 返回可识别的业务原因，不显示技术堆栈或敏感信息 | 保存失败不产生部分更改；当前授权仍须成立 |
| 离开未保存表单 | 提示“未保存的修改将丢失”，可继续编辑或放弃离开 | 不增加跨会话草稿 |

### 列表查询、分页与返回

适用于各模块列表及详情内的分页记录表。页面定义自身筛选、默认排序、计数单位、空态文案及特殊要求。

| 操作／场景 | 查询与分页规则 | 展示／返回结果 |
| --- | --- | --- |
| 首次进入／查询 | 首次按页面默认条件加载；多个有效条件取交集 | 点击“查询”应用输入，文本搜索框回车与查询等效，不逐字查询 |
| 重置 | 恢复页面默认筛选，保留每页条数 | 查询及重置回第1页 |
| 分页展示 | 按当前筛选和授权范围计算结果 | 显示总数、当前页、总页数、每页条数及上一页／下一页；计数单位按页面定义 |
| 每页条数 | 默认20条，可选20／50／100 | 切换条数回第1页，保留已执行筛选与排序 |
| 翻页 | 保留已执行筛选与排序；先完整排序再分页，同值按稳定记录引用升序 | 第1页禁用上一页，末页禁用下一页 |
| 记录变更后刷新 | 创建、删除、恢复及业务处理后刷新事实与总数，保留查询及条数 | 页码超界回最后有效页；0条显示第1页空态，总页数1，两翻页按钮禁用 |
| 返回列表 | 恢复已执行筛选、排序、条数和页码并重新加载 | 无来源上下文时返回对应授权列表 |
| 加载失败 | 保留查询上下文，允许重试 | 显示“加载失败，请重试”和“重试”；不将失败显示为0条或无数据 |
| 授权变化 | 查询、翻页及返回均按当前授权过滤 | 选项、记录及计数不泄露越权数据；失权记录不继续展示 |

## 业务时区与工作日

- 业务展示与工作日计算使用Asia/Shanghai（东八区）。
- 工作日为周一至周五，并应用可维护的节假日／调休日历；初始无特殊日历时采用周一至周五。
- 页面需要日期默认范围、计划／实际时刻或跨字段先后关系时，执行对应页面的明确条件。

## 规则适用

公共格式与错误反馈和模块业务准入同时校验。模块更严格的条件不因公共格式通过而省略。

## 模块例外

模块增加更严格的规则时，在模块PRD说明字段、场景、原因和影响。全模块共同适用的规则回写公共规范，模块特有数量、轮次、时长及关系约束在对应字段维护。

## 基线依据与变更

本文沿用已确认的文本、密码、联系方式及附件基线；本次仅重新组织并迁移招聘业务参数，不能把常见实践当作新的公司制度。

## 字典停用值的历史编辑

- 编辑其他字段时允许保留原记录已关联的停用字典值，显示“已停用”；保留只适用于原关联，不能将另一停用值作为新关联。
- 更换该字段、创建记录、复制为新记录及新增关联仅允许启用值；不要求用户为纠正无关字段而替换历史分类。
- 提交时复核当前状态。新选择在提交前被停用则拒绝新关联，保留输入并提示“该选项已停用，请重新选择”；不得保存部分更改。原值本来启用而在编辑期间被停用，未更换该字段仍属于保留原关联。
- 本规则不放宽已禁用账号、失效责任指派或状态动作准入；部门停用保留原关联与业务权限，仅禁止新关联。
- 适用全部引用公共字典的新增／编辑表单。
