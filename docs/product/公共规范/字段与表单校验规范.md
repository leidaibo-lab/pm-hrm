# 字段与表单校验规范

- **面向读者／用途**：研发与测试；实现配套需求。

- **适用范围**：HRM 全部模块，包括工作台、招聘管理和绩效管理。
- **状态**：本期校验基线，作为实现与验收依据。

## 目标

统一所有模块的表单、接口和附件校验，避免同一个字段在不同模块出现不同长度、格式和错误处理方式。

## 公共规则

以下规则默认适用于所有新增、编辑和提交表单。前端提示和服务端校验必须保持一致；服务端校验是最终准入规则。

| 规则类别 | MVP 默认规则 |
| --- | --- |
| 必填字段 | 必填字段不能为 `null`、空字符串或只包含空白字符；去除首尾空白后再校验。 |
| 文本处理 | 普通单行文本默认最多 100 个字符；备注类文本最多 2,000 个字符；长文本最多 5,000 个字符。按用户可见字符计数，不静默截断。 |
| 姓名和用户显示名 | 1-50 个字符，允许中文、英文、数字、空格和常见连接符；不允许仅由空白字符组成。 |
| 邮箱 | 最多 254 个字符，符合邮箱格式；比较唯一性时忽略大小写并去除首尾空白。 |
| 联系方式 | 至少填写一种可用联系方式；国际手机号标准化为国家码及数字，最多 15 位数字；中国大陆手机号为 11 位，国际号码需提供国家码，不将所有国家号码套用大陆规则；邮箱按邮箱规则校验。 |
| 密码 | 15-128 个字符，允许空格、Unicode及粘贴，不强制字符类别组合；拒绝常见、已泄露及与账号信息完全相同的弱密码，不定期强制改密，泄露或管理员重置时要求更新。密码不能回显，也不能写入普通日志。 |
| 正整数 | 数量字段只能填写整数，不能为 0 或负数；招聘人数范围为 1-9,999。 |
| 排序和轮次 | 面试轮次序号为 1-99，单个模板内不能重复；排序字段不能接受小数或负数。 |
| 时长 | 面试时长使用分钟保存，范围为 1-1,440 分钟。 |
| 链接 | 只允许 `http` 或 `https` 链接，最多 2,048 个字符；保存前校验格式，展示时使用安全跳转。 |
| 日期和时间 | 必须是有效日期时间；业务展示和工作日计算统一使用东八区；结束时间不能早于开始时间。 |
| 字典选项 | 创建、新增关联及换值只能选择启用值；历史编辑保留规则按下方公共字典编辑规则执行。 |
| 简历附件 | 招聘模块支持 PDF、DOC、DOCX；单个文件不超过 20 MB；必须同时校验文件扩展名、MIME 类型和实际文件内容。 |
| 文本安全 | 用户输入在展示时必须进行转义，不能执行输入内容中的脚本或 HTML；错误提示不能泄露密码、文件路径或敏感数据。 |
| 重复提交 | 创建、状态变更、合并和上传等提交操作需要防止重复执行；失败后重试不能产生重复业务记录。 |

## 通用交互要求

- 校验失败时保留用户已经填写的合法内容。
- 错误信息显示在对应字段附近，说明失败原因和修正方向。
- 前端校验只用于及时反馈，不能替代服务端权限和数据校验。
- 服务端拒绝请求时返回可识别的业务错误，不返回堆栈、文件路径、密码或其他敏感信息。
- 文件上传失败不能留下无法访问的孤立附件记录。

### 列表查询、分页与返回

默认适用于各模块列表及详情内的分页记录表；页面只定义自身筛选字段、默认排序、计数单位、空态文案及特殊要求。

| 项目 | 公共要求 |
| --- | --- |
| 查询 | 多个有效条件取交集；首次进入按页面默认条件加载。点击“查询”应用当前输入，文本搜索框回车与查询等效；不逐字触发查询 |
| 重置 | 筛选值恢复页面定义的默认条件，保留每页条数；查询／重置回第1页 |
| 分页展示 | 表格底部显示当前筛选及授权范围内的记录总数、当前页、总页数、每页条数和上一页／下一页；总数的业务单位由页面定义 |
| 每页条数 | 默认20条，可选20／50／100；切换条数回第1页，保留已执行筛选和排序 |
| 翻页 | 保留已执行筛选和排序；第1页禁用上一页，末页禁用下一页；先按完整结果排序，再按页截取；排序值相同按稳定记录引用升序 |
| 记录变更后刷新 | 创建、删除、恢复及业务处理后刷新当前事实和总数，保留原查询及条数；页码超界回最后有效页；0条时展示第1页空状态，总页数显示1，禁用上一页／下一页 |
| 返回列表 | 从详情或业务页返回，恢复原已执行筛选、排序、条数和页码并重新加载；无来源上下文时返回对应授权列表 |
| 加载失败 | 显示“加载失败，请重试”及“重试”按钮，保留查询上下文；失败不替换成0条或无数据状态 |
| 授权变化 | 查询、翻页及返回刷新均按当前授权过滤，选项、记录和计数不得泄露越权数据；失权记录不继续展示 |
| 未保存表单离开 | 提示“未保存的修改将丢失”，可继续编辑或放弃离开；不增加跨会话草稿 |

## 模块例外

模块可以增加更严格的业务规则，但必须在模块 PRD 中说明：

1. 适用的具体字段或场景。
2. 与公共规则不同的原因。
3. 对用户提示、接口和数据存储的影响。
4. 是否需要回写公共规范，成为所有模块的新默认规则。

## 基线依据与变更

本文件结合常见企业表单实践制定 MVP 默认值；文本长度、20 MB附件限制、轮次及数量上限属于项目选择，并非行业统一强制值。密码采用长口令与弱密码阻断思路；联系方式兼容国际号码，不能仅用长度推定真实有效。前后端按相同口径验收，规则变更需同步公共规范和对应场景，不再标为开发前待确认。

## 追加公共验收规则

- 密码不做首尾空白裁剪，允许密码管理器及粘贴；临时密码同样符合长度规则，首次登录和重置后的改密流程保留。
- 创建、状态流转、删除、跳轮、合并等操作遇到并发修改时拒绝覆盖过期版本，并提示刷新；同一成功动作重试不重复生成记录、轮次或待办。
- 已停用字典、账号不能用于新指派；历史值仍展示。解除角色或禁用账号后服务端下一次操作立即按新权限校验。
- 文件类型同时检查扩展名、MIME与内容；加密、损坏、带宏或可执行内容的文件不接收；不能识别时拒绝并提示转换为 PDF。附件不提供永久公开链接。
- 工作日按周一至周五及可维护节假日／调休日历计算；初始无特殊日历时采用周一至周五，业务时区为 Asia/Shanghai。

## 字典停用值的历史编辑

- 编辑其他字段时允许保留原记录已关联的停用字典值，显示“已停用”；保留只适用于原关联，不能将另一停用值作为新关联。
- 更换该字段、创建记录、复制为新记录及新增关联仅允许启用值；不要求用户为纠正无关字段而替换历史分类。
- 提交时复核当前状态。新选择在提交前被停用则拒绝新关联，保留输入并提示“该选项已停用，请重新选择”；不得保存部分更改。原值本来启用而在编辑期间被停用，未更换该字段仍属于保留原关联。
- 本规则不放宽已禁用账号、失效责任指派或状态动作准入；部门停用保留原关联与业务权限，仅禁止新关联。
- 适用全部引用公共字典的新增／编辑表单；验收TS-DICT-030，适用表单须逐项执行，不以一个表单测试代替整体覆盖。
