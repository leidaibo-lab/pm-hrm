# 招聘管理模块

- [产品能力与模块落地映射](../../产品能力与模块落地映射.md)：招聘内部能力与平台共用交付的归属、入口及验收索引。

招聘管理是当前 HRM 的首个完整业务闭环，范围从飞书职位发布完成后的职位建档，到候选人筛选、邀约、面试、评价和录用决策。

建议阅读顺序：

1. [范围说明](范围说明.md)：先了解模块边界、角色、流程和 MVP 范围。
2. [业务流程与数据流转图](业务流程与数据流转图.md)：了解数据输入输出、对象关系、角色协作及正常／非常规链路。
3. [产品需求文档](产品需求文档.md)：查看完整的模块产品需求。
4. [面试流程与评价最小配置](面试流程与评价最小配置.md)：研发默认配置、逐轮人员名单、评价字段和当前轮按钮。
5. [关键交互说明](关键交互说明.md)：候选人详情、重复对比与推荐拒绝、CTO不参与确认的文字结构。
6. [用户故事](用户故事.md)：查看按角色拆解的开发故事和验收标准。

职级流程矩阵及多轮评价归属见[PRD E.1、E.2](产品需求文档.md)，原始业务参考见[招聘流程矩阵截图](参考资料/招聘流程矩阵-2026-10-10.png)。

本模块遵循上级目录中的[公共字段与表单校验规范](../../公共规范/字段与表单校验规范.md)和[权限与数据治理规范](../../公共规范/权限与数据治理规范.md)。

当前流转及最终评价例外以[决策 D-019](../../产品探索/产品决策记录.md)、[PRD E.4](产品需求文档.md)和[最小配置第7节](面试流程与评价最小配置.md)为准：不通过直接淘汰，替代场次重新评价，CTO不参与由当前职位负责人确认并引用前轮最终评价。

重复活动流程在用人负责人初筛推荐时拦截，规则见[决策D-020](../../产品探索/产品决策记录.md)及[PRD D.1](产品需求文档.md)，验收见TS-DUP-020。

前轮迟交待定不回退、不暂停后轮、不新增录用门槛，由当前职位负责人处理；见[决策D-021](../../产品探索/产品决策记录.md)、PRD E.5及TS-LATE-021。当前实际轮或最终承接轮待定仍按D-019等待。
