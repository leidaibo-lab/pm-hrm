## 研发宣讲与联合交接

| 顺序 | 宣讲内容 | 案例与核对结果 |
| --- | --- | --- |
| 1 | 产品项目总览：目标与范围 | 飞书／Boss／HRM职责、平台与招聘归属、本期不包含什么 |
| 2 | 招聘PRD：主流程与角色交接 | 建档至决策的输入、动作、责任和输出；候选人阶段与单场状态分开 |
| 3 | 招聘PRD：字段、页面与授权 | 必填／默认、编辑条件、按钮反馈、当前权限与历史作者 |
| 4 | 招聘PRD：异常链路 | 活动重复拦截、同场换人／替代、迟交待定／不通过、CTO不参与；人员五例按平台需求核对 |
| 5 | 验收附件及共享依据 | 场景预期、实施依赖、运行评估、发布专项与真实结果记录 |

宣讲前记录Git提交、相关文档版本及交接能力范围；请研发／测试以案例复述结果，差异、承担方及处理结果记录在既有TODO／评审资料。新业务选择返回产品协作过程确认，再更新交付正文。
