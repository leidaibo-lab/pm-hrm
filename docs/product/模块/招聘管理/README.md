# 招聘管理模块

当前范围为招聘MVP：飞书审批发布后人工建档，Boss资料人工导入，至招聘决策结束；具体边界见PRD，不延伸到员工档案或入职办理。

## 研发与测试阅读顺序

1. [产品需求文档](产品需求文档.md)：业务目标、范围、角色、状态、功能与跨能力依赖。
2. [字段字典](字段字典.md)：按职位、应聘资料、筛选邀约、模板场次、评价决策集中查看字段来源、准入、修改及历史。
3. [页面交互与按钮权限](页面交互与按钮权限.md)：从页面理解操作，核对按钮权限、确认与反馈。
4. [业务流程与数据流转图](业务流程与数据流转图.md)：数据流、概念关系图、按阶段展开的角色时序泳道、数据使用对照、状态与异常图示。
5. [验收追踪](../../验收与追踪/招聘管理需求到验收追踪矩阵.md)：按需求找到场景，实际执行结果仍待记录。
