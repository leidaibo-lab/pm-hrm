# 招聘管理范围说明

本文件是范围入口，详细业务规则统一见[招聘PRD](产品需求文档.md)，字段及操作分别见[字段字典](字段字典.md)和[页面交互与按钮权限](页面交互与按钮权限.md)。不再维护完整流程、权限和异常的平行副本。

## 本期边界

| 边界 | 本期职责 |
| --- | --- |
| 飞书 | 招聘申请、审批、发布、关闭／重开事实的外部权威；HRM人工交接，不接API或日历 |
| Boss直聘 | 外部招聘沟通及简历取得，HR人工导入；HRM不建设候选人账号或平台授权流程 |
| HRM招聘 | 职位、应聘资料、筛选邀约、模板场次、评价、招聘决策与责任协作 |
| 平台 | 内部人员账号、角色、部门、字典、工作台、站内消息及审计；平台权不自动变业务权 |
| 后置 | 员工档案、Offer、薪酬、合同、入职办理及绩效，不由录用结果自动产生 |

招聘闭环从飞书发布后的建档至录用／淘汰／放弃决策止。内部人员最小范围见D-022至025，已确认规则见[产品决策记录](../../产品探索/产品决策记录.md)。完整需求归属及外部数据权威见[产品总览](../../产品总览.md)。

## 招聘字典初始值

以下选项一期作为系统字典，由管理员维护；D-039本期所有选项统一不提供物理删除，允许启停且不替换已承载的业务语义。

| 字典 | 默认初始值 |
| --- | --- |
| 职位类型 | 全职、实习、兼职、外包/合同、其他 |
| 办公方式 | 现场办公、远程、混合办公 |
| 招聘角色 | 前端、后端、客户端、测试、数据、DevOps、产品、设计、运营、其他 |
| 面试职级 | P2、P3-1、P3-2、P3-3、P4、P5；初级／潜力、中级／骨干、高级／专家为分组说明，其他职级不在本期默认流程内，出现真实需求时另行确认 |
| 面试结论 | 通过、不通过、待定/需补充 |
| 推荐结果 | 推荐、不推荐、待补充 |
| 风险项 | 无、技术能力、经验匹配、沟通协作、稳定性、薪资/到岗时间、其他 |
| 淘汰原因 | 能力不匹配、经验不足、面试表现、薪资不匹配、到岗时间不匹配、职位调整、其他 |
| 候选人放弃原因 | 公司取消、候选人取消、未到场、已接受其他机会、不再求职、薪资原因、时间安排、失联、个人原因、其他 |
