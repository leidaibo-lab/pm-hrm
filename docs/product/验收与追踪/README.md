# 验收与追踪

本目录把产品目标、模块需求、用户故事、测试场景和发布门槛连接起来，避免需求文档完成后无法确认是否真正交付。

## 追踪规则

- 每项进入 MVP 的产品能力必须有用户故事、可验证验收条件和至少一个测试场景。
- 每个测试场景必须能追溯到一个或多个用户故事，并标记当前状态。
- 发布门槛只引用已经完成验收的追踪项；待评审或待验证内容不能默认为已交付。
- 权限、敏感数据和生命周期场景必须包含正向、越权、删除、恢复和审计验证。
