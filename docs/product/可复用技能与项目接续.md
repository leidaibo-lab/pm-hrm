# 可复用技能与项目接续

- **日期**：2026-10-12。
- **已创建技能**：`product-requirements-alignment`（产品需求持续对齐）。
- **本机位置**：`~/.codex/skills/product-requirements-alignment/`；技能在项目外，不随本仓库Git提交同步到其他机器。

## 用途与职责

当用户提出继续项目、审查完整性与解耦、确认业务方案或完善研发交接时，使用该技能定位阶段和权威来源，主动识别缺口并同步决策、字段、图示、交互、故事、验收和TODO。

它提炼的是执行方法：总维度与模块分层、共性规则唯一维护、业务概念分离、字段及按钮交接、确认范围精确传播、局部缺口分级和证据区分。HRM具体规则仍在产品决策及公共／模块文档中，不复制到技能里。

| 载体 | 负责内容 |
| --- | --- |
| AGENTS.md | 项目协作约束、文档路由及权威顺序 |
| 新技能 | 在持续工作中检查和执行对齐的方法 |
| pm-skills | PRD、路线图、实验及场景等专项产品方法 |
| 产品决策与需求 | 项目当前事实、业务政策和定义 |
| TODO及追踪 | 当前执行进度和验证证据 |

## 使用方式

可在支持本机技能发现的Codex会话中显式使用：

> 使用 $product-requirements-alignment，按当前TODO继续推进，先确认最新决策及变更，完成相应产物并同步受影响文档。

默认允许自动选择；当前会话的技能列表不一定动态刷新，首次使用可显式提供技能路径或在新会话中选择。不保证仅安装技能就自动完成所有检查；每次仍以产物与验证证据核查。

其他项目可复用方法，但需先读取它自己的协作规则、文档路由、阶段与决策。不能将本项目一人一账号、按钮隐藏／禁用、招聘状态或通知周期当成通用默认政策。技能不授予提交、推送、发布或发送消息权限。

## 持续改进

遇到实际遗漏时，记录触发任务、错误判断、应有行为与改进证据；优先小范围修正技能，不不断累积全局禁令。复用失败时先区分技能未加载、项目规则未提供、方法未执行和业务证据不足。

当前技能结构校验与人工场景复核分别记录，不以语法校验宣称专业表现已被真实长期验证。
