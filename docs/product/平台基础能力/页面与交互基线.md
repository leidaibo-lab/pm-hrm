- **版本／日期**：0.11／2026-10-14。
- **面向读者**：研发、测试与设计，按承担的页面阅读。
- **状态**：文字需求基线；视觉设计、联合交接与实现验收待执行。
- **配套**：[人员与账号字段](人员账号与角色字段定义.md)、[任务与治理字段](待办消息字典与审计字段定义.md)、[公共授权](../公共规范/权限与数据治理规范.md)。字段含义在配套定义，本文件明确页面如何使用。

## 一、共用页面反馈

| 情况 | 页面反馈与处理 |
| --- | --- |
| 授权判定 | 入口、查看、编辑和提交分别鉴权；无权限隐藏操作，有权限但业务条件不足时禁用并说明原因，直接请求仍须拒绝。 |
| 提交中／提交失败 | 提交期间防重复；失败保留合法输入，认证秘密不回显。 |
| 版本冲突 | 提示刷新当前事实。 |
| 加载失败 | 提供重试，不显示为无数据。 |
| 敏感动作 | 说明目标、影响及是否可恢复；成功后更新当前事实。 |

| 阅读状态 | 枚举 | 本人消息阅读事实 | 未读／已读 | — | 只读 |
| 阅读时间 | 日期时间 | 本人标记已读的记录时刻 | 详情抽屉展示 | 未读显示“—” | 只读 |

生成时间倒序，同时间按稳定引用升序，计数单位为本人可见消息；无消息“暂无站内消息”，筛选无结果“暂无符合条件的消息”。抽屉同时展示事项已结束或不可访问提示，业务解除不抹去已发历史。不提供正文编辑、手工发送、指定收件人、删除或导出。

## 十一、审计查询页与回收列表页

### 审计查询页

管理员限平台审计，HR限招聘审计，其他参与人限自身授权操作结果；审计只读，无编辑、删除、下载或导出。

首次进入默认选择今天及前6天；重置按执行当天重新计算，查询、翻页及详情返回保留已选日期。例如2026年10月14日进入，显示10月8日至10月14日，查询范围为北京时间10月8日00:00（含）至10月15日00:00（不含）。

## 十二、招聘页面边界与设计验证

职位列表、新增、详情、编辑及候选人、筛选、场次、评价和决策的页面需求由[招聘管理PRD](../模块/招聘管理/产品需求文档.md#features)定义；本文件不另维护招聘页面行为。

本期文字交互采用：人员新增／编辑共用独立页，人员详情分账号与角色区域；部门／字典新增编辑弹窗，账号与恢复动作确认或输入弹窗；消息和审计详情只读抽屉。各页返回、列表排序与分页已在对应章节定义。视觉布局、文件预览及辅助技术可用性仍须设计和真实操作验证，不能以文字定义替代。
