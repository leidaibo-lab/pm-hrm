# 平台及简单表单交互基线

- **状态**：2026-10-12，D-039本期文字交互定义；不是视觉稿或实现验证。具体字段／授权归相应字段文档与公共规范。
- **统一机制**：入口、查看、编辑、提交分别鉴权，D-023无权隐藏／有权条件不足禁用；失败保留合法输入，冲突刷新，敏感动作提示目标与后果，成功更新当前事实。提交期间防重复，空状态不伪装错误；数据加载失败显示重试，不清空已有业务记录。

| 页面 | 入口／布局及动作 | 成功、失败、空状态／引用 |
| --- | --- | --- |
| 人员与组织 | 管理员人员列表筛部门／角色／启用；创建人员与账号一个表单，详情资料及账号状态分区 | 成功显示同一人员关联账号；邮箱冲突等字段反馈，不重复创建；空状态暂无人员。字段、首次改密、重置／禁用确认沿人员字段及平台按钮矩阵 |
| 部门 | 管理员组织设置列表，创建／改名／启停，不提供删除 | 停用提示原关联保留、新关联受限；同名拒绝；无结果显示暂无符合条件部门；D-024及公共规范 |
| 账号登录／改密 | 登录入口，需改密先完成改密；禁用拒绝不展示业务资料 | 更正邮箱／重置密码／禁用使会话失效沿D-025；身份不因重新登录新增；无自助人员资料编辑 |
| 职位列表／详情 | HR列表筛部门／状态，详情来源、责任、字段更正、关闭／重开分区 | 无职位引导合法建档；重复来源拒绝并按权限原记录入口；其他业务角色只读授权。F-03及招聘关键交互 |
| 候选人导入／版本 | HR从可招聘职位进入，来源和双联系方式分区；详情当前版本／历史 | 创建待筛选，上传成功自动当前；来源缺失明示，字段失败保留输入；无候选人引导导入；F-04及招聘关键交互 |
| 字典管理 | 管理员设置按分类与名称筛选，新增／编辑／排序／启停 | 无启用选项提示启用，不自由填业务字段；语义不能替换流程规则，无物理删除；平台字段第3节 |
| 工作台／站内消息 | 授权任务聚合与本人消息分区，筛选及跳业务入口 | 无待办／无消息各自空状态；已读与处理分开，失权通用提示，错误不变业务状态；平台字段第1、2节及招聘触发规则 |
| 审计／回收 | 授权设置入口，按时间／对象等筛选，审计只读，恢复原因及确认 | 查询无结果明示；恢复后刷新回收，失败保留原因；管理员不凭平台权见原敏感业务正文，无永久清除／导出；平台字段第4节及公共审计 |

评价／决策、安排／补录和筛选／邀约表单由招聘字段文档与关键交互承载，不为目录另建独立菜单。正式页面布局、文件预览和辅助技术可用性须实施及真实操作验证，不以此表声称完成设计验收。
